# HotWireStudio

Векторная CAM-система для подготовки управляющих программ (G-code) для станков
термической резки пенопласта горячей струной с поворотным столом оси A.

Приложение работает полностью в браузере и реализует полный цикл подготовки
производства: импорт STL-модели, разбиение на горизонтальные срезы, расчёт
силуэтов под заданными углами поворота стола, построение траектории движения
струны, симуляция и экспорт управляющей программы для контроллеров ЧПУ.

## Назначение

HotWireStudio предназначена для технологов и операторов станков термической
резки пенопласта, использующих метод горячей струны с поворотным столом.
Программа формирует управляющую программу для контроллеров LinuxCNC, Mach3
и GRBL с учётом кинематики станка, ограничений метода и технологических
параметров резки.

Основные задачи, решаемые программой:

- преобразование трёхмерной модели STL в набор горизонтальных срезов;
- вычисление силуэтов срезов под заданными углами поворота стола;
- построение траектории движения струны с учётом радиуса, подачи и выхода
  за пределы заготовки;
- прогнозирование формы готовой детали с учётом ограничений метода;
- генерация G-code для целевого контроллера;
- визуальная симуляция процесса обработки;
- формирование отчётной документации.

## Кинематическая схема станка

Станок реализует схему 2+1 оси. Струна всегда вертикальна и не имеет
возможности наклона.

| Ось | Тип | Назначение |
|---|---|---|
| **X** | Линейная | Горизонтальное перемещение струны |
| **Y** | Линейная | Вертикальное перемещение струны |
| **A** | Поворотная | Вращение стола вокруг вертикальной оси Y |

Следствие: из заготовки формируется тело, представляющее собой пересечение
силуэтных призм, полученных при каждом проходе. Чем больше проходов, тем
ближе итоговая форма к исходной 3D-модели.

## Функциональные возможности

### Импорт и подготовка модели

- Загрузка STL в бинарном и ASCII-форматах.
- Определение габаритов, объёма и количества треугольников.
- Задание ориентации по трём осям с шагом 90° и произвольным углом.
- Масштабирование и смещение относительно оси A.
- Автоматическое вписывание модели в заготовку.

### Расчёт геометрии

- Горизонтальные срезы с настраиваемым числом уровней.
- Построение выпуклой оболочки каждого среза.
- Применение опорной функции для получения силуэта под произвольным углом.
- Упрощение контура методом Дугласа–Пекера и сглаживание по алгоритму Чайкина.
- Прогнозирование формы детали как пересечения всех силуэтных призм.

### Режимы движения струны

| Режим | Описание | Оборот стола |
|---|---|---|
| Силуэт силуэт за проход | 180° |
| Радиальное | Обработка правого борта с выходом до оси | 360° |
| Равновесие | Двоичное удвоение числа граней | Не фиксирован |

### Технологические режимы

- Чередование направления обхода (зиг-заг).
- Компенсация люфта поворотной оси.
- Прогрев струны перед началом резания.
- Пауза перед поворотом стола.
- Режим постоянного включения струны до конца программы.
- Технологическое основание для удержания детали на столе.
- Три режима подрезки основания: без подрезки, на всю ширину,
  с перемычкой (2 или 4 подреза).

### Постпроцессирование

- Целевые контроллеры: LinuxCNC, Mach3, GRBL.
- Настройка M-кодов включения и выключения струны.
- Стиль комментариев: `;`, `( )`, `/`.
- Точность вывода координат: 2, 3 или 4 знака.
- Расширение файла: `.nc`, `.tap`, `.txt`, `.cnc`.
- Настраиваемые буквы обозначения осей (A–Z, кроме G и M).

### Парковка струны (Начало координат XY)

- Автоматический расчёт позиции парковки относительно заготовки.
- Ручной ввод координат X и Y.
- Настраиваемый отступ за заготовку.
- Визуальный маркер позиции парковки в сцене.
- Возврат в точку парковки после завершения программы.

### Симуляция

- Покадровая симуляция с регулируемой скоростью (×1…×100).
- Синхронизация визуализации струны, стола, прогноза детали и координат.
- Отображение развёртки траектории по всем проходам.
- Возможность отмены расчёта.
- Карта операций с переходом к выбранному проходу.

### Экспорт

- Управляющая программа в выбранном формате.
- Отчёт с параметрами обработки в формате `.txt`.
- Снимок текущего вида сцены в формате `.png`.

## Установка и запуск

### Запуск без локального сервера

1. Скачайте файл `hotwirestudio.html`.
2. Откройте файл двойным кликом в браузере.
3. Демонстрационная модель загрузится автоматически.
4. Нажмите клавишу `Space` для запуска симуляции.

При первом запуске требуется подключение к сети для загрузки библиотеки
Three.js с CDN. Для работы в изолированной среде см. раздел
«Оффлайн-развёртывание».

### Запуск через локальный сервер

Рекомендуемый способ, исключающий ограничения браузеров при работе с
протоколом `file://`.

**Python 3:**

```
python -m http.server 8000
```

**Node.js:**

```
npx serve .
```

После запуска откройте в браузере `http://localhost:8000/hotwirestudio.html`.

### Оффлайн-развёртывание

1. Загрузите файлы библиотеки Three.js из
   `cdn.jsdelivr.net/npm/three@0.161.0/`:
   - `three.module.js`
   - `examples/jsm/controls/OrbitControls.js`
2. Разместите их в каталогах `vendor/three/` и
   `vendor/three/addons/controls/`.
3. Измените карту импорта в HTML-файле:

```
<script type="importmap">
{"imports":{
"three":"./vendor/three/three.module.js",
"three/addons/":"./vendor/three/addons/"
}}
</script>
```

## Пользовательский интерфейс

Интерфейс построен по схеме трёх областей с выдвижными панелями
и нижней консолью.

### Главная сцена

Центральная область содержит трёхмерную сцену с заготовкой, моделью,
прогнозом детали, струной и маркером точки парковки.

Элементы управления на сцене:

- цифровая индикация координат X, Y, A;
- гизмо ориентации осей;
- легенда слоёв;
- панель управления симуляцией;
- кнопки видов и снимка.

### Левая панель

| Вкладка | Содержание |
|---|---|
| Модель | Импорт STL, ориентация, масштаб, смещение |
| Заготовка | Габариты заготовки, размеры станка, контроль размещения |
| Слои | Управление видимостью объектов, проекции камеры |

### Правая панель

| Вкладка | Содержание |
|---|---|
| Резание | Режим, число проходов, парковка, точность, подачи |
| Основание | Технологическое основание, подрезка, карта операций |
| G-code | Постпроцессор, служебные коды, экспорт |
| Отчёт | Сводные показатели, структура времени, экспорт отчёта |

### Нижняя консоль

| Вкладка | Содержание |
|---|---|
| Развёртка | Графическое представление силуэтов всех проходов |
| Журнал | Хронология событий программы |
| G-code | Полный текст управляющей программы |

## Технологический цикл обработки

```
Точка парковки
       │
       ▼
Подход к точке старта за пределами заготовки
       │
       ▼
Опускание на рабочую высоту Y
       │
       ▼
Прогрев струны
       │
       ▼
Включение струны (M3)
       │
       ▼
Рез по силуэту под текущим углом A
       │
       ▼
Выход за пределы заготовки
       │
       ▼
Выключение струны (M5)
       │
       ▼
Поворот стола A на заданный шаг
       │
       ▼
Повтор цикла для всех проходов
       │
       ▼
Возврат в точку парковки
```

## Ограничения метода

Метод горячей струны с вертикальной ориентацией имеет принципиальные
технологические ограничения:

1. **Внутренние полости.** Отверстия внутри детали (например, внутреннее
   пространство ручки кружки, отверстия буквы R) не формируются —
   струна обходит только внешний контур.

2. **Поднутрения.** Вогнутые участки боковой поверхности срезаются как
   выпуклая оболочка, что приводит к «заполнению» вогнутостей.

3. **Четырёхосевые поверхности.** Винтовые, спиральные и конические
   поверхности требуют наклоняемой струны с осями U и V, которые не
   реализуются в рассматриваемой схеме станка.

При наличии вогнутостей в исходной модели программа отображает
прогнозируемую форму детали в сцене, что позволяет заранее оценить
отклонения от STL.

## Диагностика и устранение неполадок

| Симптом | Возможная причина | Решение |
|---|---|---|
| Ступенчатая поверхность | Недостаточное число проходов | Увеличить значение до 48–72 |
| Тонкая перемычка у детали | Завышенный рез ниже низа модели | Уменьшить параметр или увеличить ширину перемычки |
| Избыточная длительность обработки | Завышены срезы или занижен допуск | Уменьшить число срезов, увеличить допуск |
| Отрыв детали в процессе обработки | Недостаточная высота основания | Увеличить основание или отключить подрезку |
| Модель не помещается в заготовку | Недостаточные габариты заготовки | Увеличить диаметр или высоту, уменьшить масштаб |
| Струна движется по воздуху | Слишком большой диаметр заготовки | Уменьшить диаметр или сместить модель к центру |
| Струна задевает оснастку в позиции парковки | Мал отступ за заготовку | Увеличить отступ или задать координаты вручную |
| Не выполняется импорт STL | Некорректный файл или неподдерживаемый формат | Проверить формат в CAD-системе |
| Сцена не загружается | Отсутствует WebGL 2.0 или доступ к CDN | Проверить браузер и сетевое подключение |
| Ошибка импорта модуля `three` | Не подключён importmap или отсутствует сеть | Проверить карту импорта и подключение |

## Разработка и внесение изменений

### Структура репозитория

```
hotwirestudio/
├── hotwirestudio.html      Основной файл приложения
├── README.md               Документация
├── LICENSE                 Лицензионное соглашение
├── docs/                   Изображения и демонстрационные материалы
└── examples/               Примеры STL и управляющих программ
```

### Порядок внесения изменений

1. Создайте форк репозитория.
2. Создайте рабочую ветку с описательным именем.
3. Внесите изменения и проверьте работу приложения в браузерах
   Chrome, Firefox и Safari.
4. Проверьте работу на демонстрационной модели и на двух-трёх
   собственных STL-файлах.
5. Подготовьте pull request с описанием внесённых изменений.

### Приоритетные направления развития

- Расширение перечня постпроцессоров (Mach4, PlanetCNC, Duet).
- Развитие пользовательского интерфейса.
- Локализация документации.
- Расширение возможностей прогнозирования формы детали.

### Сообщения об ошибках

При обнаружении ошибки приложите:

- описание последовательности действий;
- версию браузера и операционной системы;
- STL-файл, на котором воспроизводится ошибка (при возможности);
- содержимое консоли браузера (F12 → Console);
- снимок экрана сцены приложения.
